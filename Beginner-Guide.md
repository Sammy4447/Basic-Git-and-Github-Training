# Git & GitHub for Absolute Beginners

A simple, beginner-friendly way to learn Git and GitHub using VS Code and the terminal.

This repository is designed to help you learn by doing, not by memorizing long commands. Each lab is short, practical, and builds on the previous one.

## Why this repo is beginner-friendly

- Clear step-by-step labs
- Simple explanations before commands
- Practice with VS Code and the terminal together
- Focus on real-world Git workflows
- Encourages safe habits like working from branches

## Best way to learn

Use this method every time:

1. Read one section slowly
2. Run the command in your terminal
3. Check the result with `git status`
4. Understand what changed
5. Commit your work with a clear message
6. Move to the next lesson

This method is easier than copying commands blindly.

## Quick start

Before you begin, make sure you have:

- Git installed
- VS Code installed
- A GitHub account
- Your Git identity configured

```bash
git config --global user.name "Your Name"
git config --global user.email "you@example.com"
